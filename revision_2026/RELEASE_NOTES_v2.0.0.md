# v2.0.0 major-revision release notes

This release aligns the public repository with the major revision of Pattern Recognition manuscript PR-D-26-04876.

## Added

- E2-C controlled CIFAR-100 native/coarse 2×2 evidence and harmonized inference.
- E3 MSP and Energy output-space controls.
- E6 ViT-S controlled cross-scale replication.
- 120-checkpoint manifest with SHA-256 and verified public locations.
- Layer score-orientation, L2 secondary, severity-proxy, claim, number, and gate audits.
- Estimand and layer-status policies.
- Four-author metadata including Aleksandar Micic (ORCID 0000-0001-8606-3528).

## Changed

- Scientific framing now asks when attention entropy is reliable as a training-free OOD monitoring signal.
- Universal resolution-asymmetry, global PE-ranking, relative-PE-superiority, and Orthogonality-Trap claims from the original submission are withdrawn/superseded.
- Central cohorts use six seeds per PE family.
- Controlled CIFAR training uses MixUp (alpha=0.8) and no CutMix.

## Important statistical scope

The original E6 random-PE pre-specified replication gate remains FAIL. The fixed-PE pooled E6 result is a narrower post-audit estimand and is not a retroactive gate pass.
